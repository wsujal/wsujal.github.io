01 — Introduction

What is a Servlet?

A Servlet is a Java class that extends the functionality of a web server by dynamically generating web pages. It runs inside a Servlet Container (like Apache Tomcat) and handles HTTP requests/responses.

Client ↔ Web Server ↔ Servlet Flow

02 — Servlet Lifecycle

Servlet Life Cycle (PYQ ★★★)

The web container manages the lifecycle of a servlet through 3 methods: init(), service(), and destroy().

Servlet Lifecycle — init → service (loop) → destroy
1
Class Loading & Instantiation
The web container loads the servlet class when the first request arrives. A single instance of the servlet is created — servlet instances are shared across threads.
2
init() — Initialisation (once)
Called only once by the container after creating the instance. Used to initialise resources (DB connections, config reading). Takes a ServletConfig parameter.
3
service() — Per Request (many times)
Called for every client request. Container spawns a new thread. Checks HTTP method → calls doGet(), doPost(), etc.
4
destroy() — Cleanup (once)
Called once at end of servlet life. Used to close DB connections, stop background threads, write cookies to disk. Object is then garbage collected.

doGet() vs doPost() (PYQ ★★)

FeaturedoGet()doPost()
TriggerURL request / form with no methodForm with method="POST"
ParametersAppended to URL (?key=val)In request body (hidden)
Max Data~240 bytesNo limit
SecurityParameters visible in URLParameters encrypted/hidden
SpeedFasterSlower
Use CaseFetching data, search queriesLogin, form submission, sensitive data
DefaultYes (default HTTP method)No

Complete Servlet Code (PYQ ★)

Java — MyServlet.java
import java.io.*;
import javax.servlet.*;
import javax.servlet.http.*;

public class MyServlet extends HttpServlet {
    String msg = "";
    PrintWriter out;

    public void init(ServletConfig config) throws ServletException {
        msg = "Hello World: My First Servlet Program";
    }

    public void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        response.setContentType("text/html");
        out = response.getWriter();
        out.println("<h1>" + msg + "</h1>");
    }

    public void destroy() {
        out.close();
    }
}

web.xml — Deployment Descriptor (PYQ ★)

PYQ: "What is the deployment descriptor (web.xml)?" — It is the configuration file for a Java web app, stored in WEB-INF/web.xml. It maps servlets to URLs and passes init parameters.
XML — web.xml
<web-app>

  <servlet>
    <servlet-name>MyServlet</servlet-name>     <!-- logical name -->
    <servlet-class>MyServlet</servlet-class>   <!-- .java class name -->
    <init-param>
      <param-name>name</param-name>
      <param-value>cxcy</param-value>
    </init-param>
  </servlet>

  <servlet-mapping>
    <servlet-name>MyServlet</servlet-name>
    <url-pattern>/MyServlet</url-pattern>   <!-- URL to access -->
  </servlet-mapping>

</web-app>
03 — ServletConfig & ServletContext

ServletConfig vs ServletContext (PYQ ★★★)

ServletConfig

  • One object per servlet
  • Defined via <init-param> inside <servlet>
  • Created during servlet initialisation
  • Destroyed when servlet stops executing
  • Accessed via getInitParameter()
  • Requires first request to be created

ServletContext

  • One object per web application (global)
  • Defined via <context-param> under <web-app>
  • Created at web app deployment
  • Destroyed when app is removed from server
  • Accessed via getServletContext().getInitParameter()
  • Available even before first request

ServletConfig — web.xml + Code

XML — web.xml (init-param)
<servlet>
  <servlet-name>MyServlet</servlet-name>
  <servlet-class>MyServlet</servlet-class>
  <init-param>
    <param-name>name</param-name>
    <param-value>cxcy</param-value>
  </init-param>
</servlet>
Java — MyServlet.java (ServletConfig)
public void init(ServletConfig config) throws ServletException {
    msg = config.getInitParameter("name");  // reads from <init-param>
}

public void doGet(HttpServletRequest req, HttpServletResponse res)
        throws ServletException, IOException {
    res.setContentType("text/html");
    PrintWriter out = res.getWriter();
    out.println("<h1>" + msg + "</h1>");  // prints: cxcy
}

ServletContext — web.xml + Code

XML — web.xml (context-param)
<web-app>
  <context-param>               <!-- Global to ALL servlets -->
    <param-name>name</param-name>
    <param-value>EXAMPLE</param-value>
  </context-param>
  <servlet>...</servlet>
</web-app>
Java — ServletContextDemo.java
public void doGet(HttpServletRequest req, HttpServletResponse res)
        throws ServletException, IOException {
    PrintWriter out = res.getWriter();
    ServletContext context = getServletContext();              // get global object
    String college = context.getInitParameter("name");       // reads context-param
    out.println("College name is = " + college);              // prints: EXAMPLE
}
04 — RequestDispatcher

RequestDispatcher (PYQ ★★★)

RequestDispatcher provides the facility of dispatching (forwarding or including) a request to another resource — which can be a Servlet, JSP, or HTML file.

PYQ: "What is Request Dispatcher? Difference between forward() and include()?"

forward() vs include()

forward() — Servlet 1 hands off completely to Servlet 2
include() — Servlet 1 includes Servlet 2's output into its own response
Featureforward()include()
Works atServer sideServer side
RequestSame request/response forwardedSame request/response included
ControlTransfers completely to targetReturns to calling servlet after include
ResponseTarget generates full responseTarget's output merged into caller's response
URL changeURL does NOT change in browserURL does NOT change in browser
Use CaseRedirect on success (e.g. login success)Include header/footer components

forward() vs sendRedirect()

Featureforward()sendRedirect()
Works atServer sideClient side
RequestSame request forwardedNew request sent by browser
Server scopeSame server onlyCan go to external URLs
URL changeNo — URL stays sameYes — browser URL changes
SpeedFasterSlower (extra round trip)

RequestDispatcher Login Program (PYQ ★★)

Java — CallServlet.java (forward + include)
public class CallServlet extends HttpServlet {
    public void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        response.setContentType("text/html");
        PrintWriter out = response.getWriter();
        RequestDispatcher rd;

        String login = request.getParameter("login");
        String pwd   = request.getParameter("pwd");

        if (login.equals("java") && pwd.equals("servlet")) {
            rd = request.getRequestDispatcher("FwdDemo");
            rd.forward(request, response);    // SUCCESS: full hand-off
        } else {
            out.println("<h1>Incorrect Login/Password</h1>");
            rd = request.getRequestDispatcher("/1.html");
            rd.include(request, response);    // FAIL: include login form again
        }
    }
}
05 — Session Tracking

Session Management (PYQ ★★★)

HTTP is stateless — each request is independent. Session tracking maintains user state across multiple requests. There are 4 techniques:

A hidden (invisible) text field carries session data between pages. The user cannot see it but it's embedded in the form HTML.

Advantage

  • Easy to implement
  • Works even if cookies disabled

Disadvantage

  • Only works with forms (no hyperlinks)
  • Visible in page source
  • Only text data
HTML — Hidden Field
<form action="/Session/Valid" method="POST">
  <input type="text"   name="login">
  <input type="password" name="pwd">
  <input type="hidden" name="session_id" value="054">  <!-- invisible -->
  <input type="submit">
</form>
Java — Read hidden field in servlet
String session = request.getParameter("session_id");  // "054"
String login   = request.getParameter("login");

A token/session ID is appended to the URL: URL?name1=val1&name2=val2. When the user clicks the link, the parameters are sent to the server.

Advantage

  • Works even if cookies disabled
  • No extra form submission needed

Disadvantage

  • Works only with links
  • Parameters visible in URL (security)
  • URL length limit
Java — Url1.java (send via URL)
String url = "http://localhost:8080/Session/Url2?s_id1=054&s_id2=055";
out.println("<a href=" + url + ">next page</a>");
Java — Url2.java (read from URL)
String session1 = request.getParameter("s_id1");  // "054"
String session2 = request.getParameter("s_id2");  // "055"

A cookie is a small piece of information stored in the browser cache and automatically sent with every subsequent request to the same server.

Cookie Flow

Advantage

  • Simplest technique
  • Maintained at client side

Disadvantage

  • Fails if cookies disabled in browser
  • Only text data
Java — Create, Retrieve, Delete Cookie (PYQ ★★★)
// CREATE and ADD cookie
Cookie c = new Cookie("session_id", "054");
c.setMaxAge(3600);          // persist for 1 hour (seconds)
response.addCookie(c);    // add to response

// RETRIEVE all cookies
Cookie[] cookies = request.getCookies();
if (cookies != null) {
    for (Cookie ck : cookies) {
        out.println(ck.getName() + " = " + ck.getValue());
    }
}

// DELETE a cookie (set age to 0)
Cookie del = new Cookie("session_id", "");
del.setMaxAge(0);         // 0 = delete immediately
response.addCookie(del);

HttpSession creates a session object on the server side for each client. A unique session ID is managed by the container. Default timeout: 30 minutes.

Java — HttpSession Create, Read, Invalidate (PYQ ★★)
// CREATE / GET session (creates if none exists)
HttpSession hs = request.getSession();
hs.setAttribute("s_id", login);   // store value in session

// RETRIEVE from session (false = don't create new)
HttpSession hs = request.getSession(false);
String name = (String) hs.getAttribute("s_id");

// INVALIDATE session on logout
hs.invalidate();

// SESSION TIMEOUT in web.xml (minutes)
// <session-config><session-timeout>10</session-timeout></session-config>

// OR programmatically (seconds)
hs.setMaxInactiveInterval(10 * 60);
MethodDescription
getSession()Returns existing session or creates new one
getSession(false)Returns existing session, null if none
setAttribute(name, val)Stores an object in the session
getAttribute(name)Retrieves stored object
invalidate()Destroys the session (logout)
getId()Returns unique session ID string
getCreationTime()Time session was created (ms)

06 — Filters

Filter API (PYQ ★★)

A Filter intercepts requests before they reach a servlet and responses after they leave it. Filters are configured in web.xml and are pluggable — removing from web.xml removes the filter without touching servlet code.

Filter Chain — Request & Response flow

Filter Interface Methods

MethodCalled WhenPurpose
init(FilterConfig config)Once — filter loadedInitialise filter, read config params
doFilter(req, res, chain)Every request to mapped URLPerform filtering logic; call chain.doFilter() to pass on
destroy()Once — filter unloadedCleanup resources

Filter Interfaces in javax.servlet

InterfacePurpose
FilterMain filter interface — implement this to create a filter
FilterChainPasses request to next filter or servlet via chain.doFilter()
FilterConfigLike ServletConfig — reads <init-param> defined for filter in web.xml

Filter Configuration in web.xml (PYQ ★)

XML — web.xml (filter configuration)
<filter>
  <filter-name>f1</filter-name>
  <filter-class>Filter1</filter-class>
  <init-param>                       <!-- FilterConfig reads this -->
    <param-name>permit</param-name>
    <param-value>yes</param-value>
  </init-param>
</filter>

<filter-mapping>
  <filter-name>f1</filter-name>
  <url-pattern>/FilteredServlet</url-pattern>  <!-- applies to this URL -->
</filter-mapping>

Filter Implementation + FilterConfig (PYQ ★)

Java — Filter1.java (Auth + FilterConfig)
public class Filter1 implements Filter {
    String permission;

    public void init(FilterConfig config) throws ServletException {
        permission = config.getInitParameter("permit"); // reads from web.xml
    }

    public void doFilter(ServletRequest req, ServletResponse res, FilterChain chain)
            throws IOException, ServletException {
        PrintWriter out = res.getWriter();
        out.print("<p>Filter invoked BEFORE servlet</p>");

        String login = req.getParameter("login");
        String pwd   = req.getParameter("pwd");

        if (login.equals("java") && pwd.equals("servlet")
                && permission.equals("yes")) {
            chain.doFilter(req, res);   // pass to next filter/servlet
        } else {
            out.print("<p>Access Denied</p>");
        }

        out.print("<p>Filter invoked AFTER servlet</p>");
    }

    public void destroy() { }
}

Program 1 — Employee Form + Servlet + JDBC (PYQ ★★★)

HTML form → Servlet reads data → saves to MySQL Employee table (EmpId, EName, Email, Age).

HTML — employee.html
<!DOCTYPE html>
<html><body>
<form action="/EmpApp/EmpServlet" method="POST">
  <p>Emp ID   : <input type="text"  name="empid"></p>
  <p>Name     : <input type="text"  name="ename"></p>
  <p>Email    : <input type="email" name="email"></p>
  <p>Age      : <input type="number"name="age"  ></p>
  <p><input type="submit" value="Add Employee"></p>
</form>
</body></html>
Java — EmpServlet.java
import java.io.*;
import java.sql.*;
import javax.servlet.*;
import javax.servlet.http.*;

public class EmpServlet extends HttpServlet {

    public void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        response.setContentType("text/html");
        PrintWriter out = response.getWriter();

        // Read form data
        int    empId = Integer.parseInt(request.getParameter("empid"));
        String eName = request.getParameter("ename");
        String email = request.getParameter("email");
        int    age   = Integer.parseInt(request.getParameter("age"));

        try {
            Class.forName("com.mysql.jdbc.Driver");
            Connection con = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/ajava", "root", "root");

            // Use PreparedStatement to insert record
            PreparedStatement ps = con.prepareStatement(
                "INSERT INTO Employee(EmpId, EName, Email, Age) VALUES(?,?,?,?)");
            ps.setInt   (1, empId);
            ps.setString(2, eName);
            ps.setString(3, email);
            ps.setInt   (4, age);

            int rows = ps.executeUpdate();
            if (rows > 0)
                out.println("<h2>Employee added successfully!</h2>");
            else
                out.println("<h2>Insert failed.</h2>");

            ps.close(); con.close();
        } catch (Exception e) {
            out.println("Error: " + e.toString());
        }
    }
}

Program 2 — Login Servlet with Database Auth (PYQ ★★)

Java — LoginServlet.java
public class LoginServlet extends HttpServlet {
    public void doPost(HttpServletRequest req, HttpServletResponse res)
            throws ServletException, IOException {
        res.setContentType("text/html");
        PrintWriter out = res.getWriter();

        String user = req.getParameter("username");
        String pwd  = req.getParameter("password");

        try {
            Class.forName("com.mysql.jdbc.Driver");
            Connection con = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/ajava", "root", "root");

            PreparedStatement ps = con.prepareStatement(
                "SELECT * FROM Users WHERE username=? AND password=?");
            ps.setString(1, user);
            ps.setString(2, pwd);
            ResultSet rs = ps.executeQuery();

            if (rs.next()) {
                // Create session on successful login
                HttpSession hs = req.getSession();
                hs.setAttribute("user", user);
                out.println("<h2>Welcome, " + user + "!</h2>");
            } else {
                out.println("<h2>Invalid credentials.</h2>");
                RequestDispatcher rd = req.getRequestDispatcher("/login.html");
                rd.include(req, res);
            }
            con.close();
        } catch (Exception e) { out.println(e); }
    }
}
