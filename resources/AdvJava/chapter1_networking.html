01 — Foundations

Network Basics & Terminology

A network is an interconnection of computing devices (via cable or wireless) for resource sharing. Devices that consume services are clients; devices that provide services are servers.

Key Terminology

TermDefinition
IP AddressUnique identification number for every device on a network.
DNSDomain Name Service — maps IP addresses to readable website names.
Port Number2-byte (0–65535) unique ID for a socket on a machine.
URLUniform Resource Locator — global address of a web resource.
TCP/IPConnection-oriented, reliable protocol. Data arrives in order.
UDPConnection-less, unreliable but faster protocol.

java.net package

Java's java.net package provides all networking classes. They fall into two groups:

  • Identification/Connection: InetAddress, URL, URLConnection
  • Communication (send/receive): Socket, ServerSocket, DatagramPacket, DatagramSocket
02 — InetAddress

InetAddress Class

InetAddress (in java.net) encapsulates both the numerical IP address and the host name. You cannot instantiate it with new — use its static factory methods.

PYQ: "How do you get the IP address of a machine from its hostname?" — use InetAddress.getByName(hostname).
MethodDescription
getByName(String host)Returns InetAddress for given hostname. Throws UnknownHostException.
getAllByName(String host)Returns array of all IP addresses for a hostname.
getLocalHost()Returns InetAddress of the local machine.
getHostName()Returns the host name string of this InetAddress.
getHostAddress()Returns IP address as a dotted-decimal string.

getByName() — Resolve hostname → IP

Java
import java.net.*;

public class Address {
    public static void main(String[] args) {
        try {
            InetAddress ip = InetAddress.getByName("www.example.in");
            System.out.println("IP: " + ip);
        } catch (UnknownHostException e) {
            System.out.println(e);
        }
    }
}
Output
IP: www.example.ac.in/192.168.23.1

getAllByName() — Get all IPs for a host

Java
InetAddress[] addressList = InetAddress.getAllByName("wixnets.com");
for (int i = 0; i < addressList.length; i++) {
    System.out.println(addressList[i]);
}

wixnets.com/172.67.198.137
wixnets.com/104.18.49.113

getLocalHost() — Your own machine's address

Java
InetAddress localhost = InetAddress.getLocalHost();
System.out.println("LocalHost: " + localhost);
Output

getHostName() & getHostAddress() — Combined Program

Java
import java.net.*;

public class Address {
    public static void main(String[] args) {
        try {
            InetAddress ip = InetAddress.getByName("www.example.in");
            System.out.println("Host Name: "    + ip.getHostName());
            System.out.println("IP Address: "  + ip.getHostAddress());
        } catch (UnknownHostException e) {
            System.out.println(e);
        }
    }
}
Output
Host Name: www.example.in
IP Address: 192.168.23.1
03 — URL

URL Class

A URL (Uniform Resource Locator) uniquely identifies resources on the internet. It has four components:

Constructors

Java — URL Constructors
// Full constructor
URL obj = new URL(String protocol, String host, int port, String path);

// Without explicit port
URL obj = new URL(String protocol, String host, String path);

// Single string
URL obj = new URL(String urlSpecifier);

Important Methods

MethodReturns
getProtocol()Protocol (e.g. http)
getHost()Hostname
getPort()Port number (-1 if not specified)
getFile()File/path part
getQuery()Query string after ?
getDefaultPort()Default port for the protocol
openConnection()Returns a URLConnection instance
toURI()Converts URL to URI

Example Program

Java
import java.net.*;

public class URLDemo {
    public static void main(String[] args) {
        try {
            URL url = new URL("http://www.example.in/EXAMPLE");
            System.out.println("Protocol: " + url.getProtocol());
            System.out.println("Host    : " + url.getHost());
            System.out.println("Port    : " + url.getPort());
            System.out.println("File    : " + url.getFile());
        } catch (MalformedURLException e) {
            System.out.println(e);
        }
    }
}
Output
Protocol: http
Host    : www.example.in
Port    : -1
File    : /EXAMPLE
Note: Port returns -1 when not explicitly set in the URL — it means the protocol's default port (80 for HTTP) is used.
04 — URLConnection

URLConnection Class

URLConnection lets you actually connect to a URL and inspect its headers or read its content. Obtain it via url.openConnection().

PYQ: "Explain URL and URLConnection class with example." — URL identifies the resource; URLConnection opens the connection and lets you read metadata and content.

How to create

Java
URL url = new URL("https://example.com");
URLConnection conn = url.openConnection();

Key Methods

MethodDescription
getContentLength()Content size in bytes (int)
getContentLengthLong()Content size in bytes (long) — JDK 7+
getContentType()MIME type of content (e.g. text/html)
getDate()Response date in milliseconds
getExpiration()Expiry timestamp of resource
getHeaderField(String name)Value of a named HTTP header
getInputStream()Read raw content from the connection
getOutputStream()Write data to the connection

Example Program — Read page details & content

Java
import java.net.*;
import java.io.*;
import java.util.*;

public class URLConnectionDemo {
    public static void main(String[] args) {
        try {
            URL url = new URL("https://www.w3schools.com/html/default.asp");
            URLConnection con = url.openConnection();

            System.out.println("Date         : " + new Date(con.getDate()));
            System.out.println("Content-Type : " + con.getContentType());
            System.out.println("Expiry       : " + con.getExpiration());
            System.out.println("Length       : " + con.getContentLength());

            if (con.getContentLength() > 0) {
                int ch;
                InputStream in = con.getInputStream();
                while ((ch = in.read()) != -1) {
                    System.out.print((char) ch);
                }
            }
        } catch (Exception e) {
            System.out.println(e);
        }
    }
}

05 — TCP/IP Sockets

Sockets & Client–Server Architecture

A socket is one endpoint of a two-way communication link — a combination of an IP address + port number. Java provides two classes:

  • ServerSocket — used on the server side to listen for incoming connections.
  • Socket — used on the client side (and returned by accept() on the server).
PYQ: "Compare Socket with ServerSocket" / "Differences between TCP socket and UDP socket"

Socket (Client)

  • Created with hostname + port
  • Initiates the connection
  • Uses getInputStream() / getOutputStream() to communicate
  • Class: java.net.Socket

ServerSocket (Server)

  • Created with just a port number
  • Waits via accept()
  • accept() blocks until a client connects, then returns a Socket
  • Class: java.net.ServerSocket

TCP vs UDP — Key Differences

FeatureTCPUDP
ConnectionConnection-orientedConnectionless
ReliabilityGuaranteed deliveryNo guarantee
OrderData arrives in orderMay arrive out of order
SpeedSlower (overhead)Faster
Java ClassesSocket, ServerSocketDatagramSocket, DatagramPacket
Use CaseFile transfer, HTTPVideo streaming, DNS

Socket Methods

MethodDescription
getInetAddress()Returns remote address of the socket
getPort()Returns remote port number
getLocalPort()Returns local port number
getInputStream()Returns InputStream to receive data
getOutputStream()Returns OutputStream to send data
connect(addr, timeout)Connects with a timeout

06 — TCP Programs

TCP Socket Programs

Program 1 — Simple Message: Server → Client

Server sends "Hello client"; client receives and prints it.

Java — MyServer.java
import java.net.*;
import java.io.*;

public class MyServer {
    public static void main(String[] args) {
        try {
            ServerSocket ss = new ServerSocket(888);   // Step 1: bind to port
            Socket s = ss.accept();                    // Step 2: wait for client

            OutputStream obj = s.getOutputStream();   // Step 3: get output stream
            PrintStream ps = new PrintStream(obj);

            ps.println("Hello client");               // Step 4: send data

            ss.close(); s.close(); ps.close();        // Step 5: close all
        } catch (IOException ex) { ex.printStackTrace(); }
    }
}
Java — MyClient.java
import java.net.*;
import java.io.*;

public class MyClient {
    public static void main(String[] args) {
        try {
            Socket s = new Socket("localhost", 888);    // Step 1: connect to server

            InputStream inStr = s.getInputStream();    // Step 2: get input stream
            BufferedReader br =
                new BufferedReader(new InputStreamReader(inStr));

            String msg = br.readLine();               // Step 3: read data
            System.out.println("Message: " + msg);

            br.close(); s.close();                    // Step 4: close
        } catch (IOException ex) { ex.printStackTrace(); }
    }
}
Client Output
Message: Hello client

Program 2 — Echo: Client sends string, Server echoes it back (PYQ ★)

Java — EchoServer.java
import java.net.*;
import java.io.*;

public class EchoServer {
    public static void main(String[] args) throws Exception {
        ServerSocket ss = new ServerSocket(9000);
        System.out.println("Server waiting...");
        Socket s = ss.accept();

        // Read from client
        BufferedReader br = new BufferedReader(
            new InputStreamReader(s.getInputStream()));
        String received = br.readLine();
        System.out.println("Received: " + received);

        // Echo back to client
        PrintStream ps = new PrintStream(s.getOutputStream());
        ps.println(received);  // echo same string

        ss.close(); s.close();
    }
}
Java — EchoClient.java
import java.net.*;
import java.io.*;

public class EchoClient {
    public static void main(String[] args) throws Exception {
        Socket s = new Socket("localhost", 9000);

        // Send string to server
        PrintStream ps = new PrintStream(s.getOutputStream());
        ps.println("Hello from Client!");

        // Receive echo from server
        BufferedReader br = new BufferedReader(
            new InputStreamReader(s.getInputStream()));
        System.out.println("Echo: " + br.readLine());

        s.close();
    }
}

Program 4 — Word/Char/Digit Count (PYQ ★★★)

Client sends a string; server counts words, characters, digits and sends result back.

Java — CountServer.java
import java.net.*;
import java.io.*;

public class CountServer {
    public static void main(String[] args) throws Exception {
        ServerSocket ss = new ServerSocket(9002);
        Socket s = ss.accept();

        BufferedReader br = new BufferedReader(
            new InputStreamReader(s.getInputStream()));
        String str = br.readLine();

        int words   = str.trim().split("\\s+").length;
        int chars   = str.length();
        int digits  = 0;
        for (char c : str.toCharArray())
            if (Character.isDigit(c)) digits++;

        PrintStream ps = new PrintStream(s.getOutputStream());
        ps.println("Words=" + words + ", Chars=" + chars + ", Digits=" + digits);

        ss.close(); s.close();
    }
}
Sample (input: "hello world 42")
Words=3, Chars=14, Digits=2

Program 5 — Multiple Clients (Threading) (PYQ ★)

PYQ: "How do you handle multiple clients concurrently in socket programming?" — Use a new Thread per accepted connection.
Java — MultiServer.java
import java.net.*;
import java.io.*;

class ClientHandler extends Thread {
    Socket s;
    ClientHandler(Socket s) { this.s = s; }

    public void run() {
        try {
            BufferedReader br = new BufferedReader(
                new InputStreamReader(s.getInputStream()));
            PrintStream ps = new PrintStream(s.getOutputStream());
            String msg = br.readLine();
            ps.println("Server got: " + msg);
            s.close();
        } catch (IOException e) { e.printStackTrace(); }
    }
}

public class MultiServer {
    public static void main(String[] args) throws Exception {
        ServerSocket ss = new ServerSocket(9003);
        System.out.println("Waiting for clients...");
        while (true) {
            Socket s = ss.accept();               // accept a client
            new ClientHandler(s).start();       // handle in new thread
        }
    }
}
07 — UDP / Datagrams

Datagrams — DatagramSocket & DatagramPacket

Datagrams are self-contained data bundles sent via UDP. Delivery, order, and integrity are not guaranteed. Java implements datagrams with two classes:

  • DatagramPacket — the data container
  • DatagramSocket — the mechanism to send/receive packets

DatagramSocket Constructors

Java
// Any available port (for sender)
DatagramSocket ds = new DatagramSocket();

// Specific port (for receiver)
DatagramSocket ds = new DatagramSocket(int port);

// Specific port + address
DatagramSocket ds = new DatagramSocket(int port, InetAddress addr);

DatagramPacket Constructors

Java
// For RECEIVING — just buffer and size
DatagramPacket dp = new DatagramPacket(byte[] buffer, int size);

// For SENDING — data + destination address + port
DatagramPacket dp = new DatagramPacket(byte[] data, int size,
                        InetAddress address, int port);

UDP Sender & Receiver Program (PYQ ★★)

Java — UDPReceiver.java (run first)
import java.net.*;

public class UDPReceiver {
    public static void main(String[] args) {
        try {
            DatagramSocket ds = new DatagramSocket(6666);   // Step 1: bind to port
            byte[] buffer = new byte[1024];
            DatagramPacket dp = new DatagramPacket(buffer, 1024);

            ds.receive(dp);                                    // Step 2: wait for data

            String str = new String(dp.getData(), 0, dp.getLength());
            System.out.println("Received: " + str);            // Step 3: print data

            ds.close();
        } catch (Exception e) { e.printStackTrace(); }
    }
}
Java — UDPSender.java (run second)
import java.net.*;

public class UDPSender {
    public static void main(String[] args) {
        try {
            DatagramSocket ds = new DatagramSocket();          // Step 1: create socket
            String str = "Message from Sender";
            InetAddress ip = InetAddress.getByName("localhost");

            DatagramPacket dp = new DatagramPacket(
                str.getBytes(), str.length(), ip, 6666);     // Step 2: build packet

            ds.send(dp);                                       // Step 3: send
            ds.close();
        } catch (Exception e) { e.printStackTrace(); }
    }
}
Receiver Output
Received: Message from Sender

UDP File Transfer (PYQ ★)

PYQ: "Client will request to download the file from server and server will send it to client" — server reads a file into byte array and sends it as a DatagramPacket.
Java — FileServer.java (UDP)
import java.net.*;
import java.io.*;
import java.nio.file.*;

public class FileServer {
    public static void main(String[] args) throws Exception {
        DatagramSocket ds = new DatagramSocket(7777);

        // Wait for client request
        byte[] req = new byte[256];
        DatagramPacket request = new DatagramPacket(req, req.length);
        ds.receive(request);
        String fileName = new String(request.getData(), 0, request.getLength());
        System.out.println("Client wants: " + fileName);

        // Read file and send
        byte[] fileData = Files.readAllBytes(Paths.get(fileName));
        InetAddress clientAddr = request.getAddress();
        int clientPort = request.getPort();

        DatagramPacket response = new DatagramPacket(
            fileData, fileData.length, clientAddr, clientPort);
        ds.send(response);
        System.out.println("File sent!");
        ds.close();
    }
}
Java — FileClient.java (UDP)
import java.net.*;
import java.io.*;

public class FileClient {
    public static void main(String[] args) throws Exception {
        DatagramSocket ds = new DatagramSocket();
        InetAddress ip = InetAddress.getByName("localhost");

        // Send file request
        String request = "test.txt";
        DatagramPacket req = new DatagramPacket(
            request.getBytes(), request.length(), ip, 7777);
        ds.send(req);

        // Receive file data
        byte[] buf = new byte[65507];
        DatagramPacket resp = new DatagramPacket(buf, buf.length);
        ds.receive(resp);

        FileOutputStream fos = new FileOutputStream("received_test.txt");
        fos.write(resp.getData(), 0, resp.getLength());
        fos.close();
        System.out.println("File received and saved!");
        ds.close();
    }
}
