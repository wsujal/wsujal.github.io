01 — Introduction

What is JDBC?

JDBC (Java Database Connectivity) is a standard Java API used to connect Java applications to relational databases in a database-independent and platform-independent manner. It is a specification from Sun Microsystems that provides classes and interfaces in the java.sql package.

PYQ: "What is JDBC?" — JDBC is a Java API that allows programs to make database connections, execute SQL, and process results, independent of the underlying RDBMS (MySQL, Oracle, SQLite, etc.).

Just like Java's motto is "Write Once, Run Anywhere", JDBC's goal is "Write Once, Run with Any Database."

JDBC allows Java programs to:

  • Open a connection to a database
  • Create and send SQL statements
  • Execute SQL and receive results
  • Close the connection

02 — Driver Types

JDBC Driver Types

A JDBC driver is a RDBMS-specific implementation of the JDBC API interfaces. There are 4 types:

Type 1 — JDBC-ODBC Bridge Driver

Also called: JDBC-ODBC Bridge Driver. Translates JDBC calls → ODBC calls → uses Windows ODBC built-in drivers. Removed from JDK 8+. Example: MS Access.

AdvantagesDisadvantages
Works with all ODBC-supported DBsSlow — many translation layers
Vendor independentODBC must be installed on every client
—Uses Java Native Interface (JNI)
—Not suitable for production; only dev/test
Type 2 — Native Code Driver

Also called: Native API Driver / JNI Driver. Converts JDBC calls to native database API calls (C/C++). Vendor client library must be installed on each client machine. Example: Oracle OCI Driver.

AdvantagesDisadvantages
Faster than Type 1 (no ODBC overhead)Vendor client library required on each machine
Good for server-side applicationsPlatform dependent
—Does not support applets
Type 3 — Java Protocol / Middleware Driver

Also called: Java Protocol / Middleware Driver. Pure Java. Uses network sockets to communicate with a middleware server which handles the actual DB calls. A single driver can connect to multiple databases. Example: IDS Driver, Weblogic RMI Driver.

AdvantagesDisadvantages
No DB vendor library needed on clientSlower — extra network hops to middleware
One driver → multiple databasesMiddleware layer needs DB-specific coding
Switch DB by changing middleware configAdditional latency from middleware
Type 4 — Database Protocol / Pure Java Driver ⭐ Most Used

Also called: Direct to Database / Pure Java Driver. Communicates directly with DB via socket. No middleware. No native libraries. Most widely used today. Example: com.mysql.jdbc.Driver, Oracle Thin Driver.

AdvantagesDisadvantages
100% Java — fully platform independentDifferent driver needed per DB vendor
No native/client libraries requiredDB-vendor specific protocol used
Best performance — no intermediary layers—
Secure — uses DB-specific protocol directly—

03 — JDBC Steps

5 Steps of JDBC Programming

Every JDBC program follows this fixed sequence:

1
Load the JDBC Driver
Registers the driver with DriverManager using Class.forName().
2
Establish Connection
Use DriverManager.getConnection(url, user, password) to get a Connection object.
3
Create & Execute Statement
Use conn.createStatement() and then executeQuery() / executeUpdate() / execute().
4
Process ResultSet
Iterate with rs.next() and read columns with rs.getString(), rs.getInt(), etc.
5
Close Connection
Call rs.close(), stmt.close(), conn.close() to release resources.
PYQ: "What is connection URL? How do you make a database connection?" — use DriverManager.getConnection("jdbc:mysql://localhost:3306/dbname","root","pwd") after loading the driver class.

First JDBC Program — SELECT all records

Java — ConnDemo.java
import java.sql.*;

public class ConnDemo {
    public static void main(String[] args) {
        try {
            // Step 1: Load Driver
            Class.forName("com.mysql.jdbc.Driver");

            // Step 2: Establish Connection
            Connection conn = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/gtu", "root", "pwd");

            // Step 3: Create Statement & Execute Query
            Statement stmt = conn.createStatement();
            ResultSet rs = stmt.executeQuery("SELECT * FROM diet");

            // Step 4: Process Results
            while (rs.next()) {
                System.out.print(rs.getInt(1) + "\t");
                System.out.print(rs.getString("Name") + "\t");
                System.out.println(rs.getString(3));
            }

            // Step 5: Close
            stmt.close();
            conn.close();

        } catch (Exception e) { System.out.println(e); }
    }
}

04 — Statement Types

Statement, PreparedStatement, CallableStatement

Statement

  • General-purpose SQL access
  • Cannot accept parameters
  • SQL compiled every time
  • Slower for repeated queries
  • Risk of SQL injection

PreparedStatement

  • Precompiled SQL
  • Accepts ? parameters at runtime
  • Compiled only once → faster
  • Safe against SQL injection
  • Extends Statement

CallableStatement

  • Calls stored procedures in DB
  • Supports IN, OUT, INOUT params
  • Logic runs inside DB → fastest
  • Use prepareCall("{call proc(?,?)}")
  • Extends PreparedStatement

Statement — Static SQL

Java
Statement stmt = conn.createStatement();

// SELECT — returns ResultSet
ResultSet rs = stmt.executeQuery("SELECT * FROM diet");

// UPDATE — returns rows affected
int rows = stmt.executeUpdate(
    "UPDATE diet SET Name='abc601' WHERE Enr_no=601");

PreparedStatement — Parameterised SQL (PYQ ★★★)

PYQ: "What is the use of PreparedStatement? How will you use it?" — It precompiles SQL with ? placeholders. Values are set at runtime using setXXX() methods. Faster than Statement for repeated queries, and safe from SQL injection.
Java — PreparedInsert.java
import java.sql.*;

public class PreparedInsert {
    public static void main(String[] args) {
        try {
            Class.forName("com.mysql.jdbc.Driver");
            Connection conn = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/gtu", "root", "pwd");

            // ? = placeholder for parameters
            String query = "INSERT INTO dietstudent VALUES(?,?,?,?)";
            PreparedStatement ps = conn.prepareStatement(query);

            // Set parameter values by index (1-based)
            ps.setString(1, "14092");         // Enr_no
            ps.setString(2, "abc_comp");      // Name
            ps.setString(3, "computer");      // Branch
            ps.setString(4, "cx");             // Division

            int i = ps.executeUpdate();
            System.out.println("Rows inserted: " + i);

            ps.close(); conn.close();
        } catch (Exception e) { System.out.println(e); }
    }
}

PreparedStatement Methods

MethodDescription
setInt(int index, int val)Sets integer at parameter position
setString(int index, String val)Sets String at parameter position
setFloat(int index, float val)Sets float value
setDouble(int index, double val)Sets double value
executeUpdate()For INSERT/UPDATE/DELETE — returns rows affected
executeQuery()For SELECT — returns ResultSet

CallableStatement — Stored Procedures (PYQ ★★)

PYQ: "What is the use of CallableStatement? How will you use it?" — CallableStatement calls stored procedures. It supports IN (input), OUT (output), and INOUT parameters. Use conn.prepareCall("{call procName(?,?)}").
Parameter TypeDescriptionMethods
INInput value passed to proceduresetXXX()
OUTValue returned by procedureregisterOutParameter(), getXXX()
INOUTBoth input and outputsetXXX() + getXXX()
Java — CallableDemo.java
import java.sql.*;

public class CallableDemo {
    public static void main(String[] args) {
        try {
            Class.forName("com.mysql.jdbc.Driver");
            Connection conn = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/gtu", "root", "pwd");

            // Syntax: {call procedureName(IN_param, OUT_param)}
            CallableStatement cs = conn.prepareCall("{call gettitle(?,?)}");

            cs.setInt(1, 1201);                              // IN param
            cs.registerOutParameter(2, Types.VARCHAR);      // register OUT param

            cs.execute();

            System.out.println("Title: " + cs.getString(2)); // read OUT param

            cs.close(); conn.close();
        } catch (Exception e) { System.out.println(e); }
    }
}
05 — ResultSet

ResultSet & Metadata

A ResultSet holds the rows returned by a SELECT query. A cursor points to the current row. Use next() to advance, and getXXX() to read values.

ResultSet Types & Concurrency

ConstantMeaning
TYPE_FORWARD_ONLYCursor moves forward only (default)
TYPE_SCROLL_INSENSITIVEScrollable; not sensitive to DB changes after creation
TYPE_SCROLL_SENSITIVEScrollable; reflects live DB changes
CONCUR_READ_ONLYRead-only result set
CONCUR_UPDATABLEUpdatable result set
Java — Scrollable ResultSet
Statement stmt = conn.createStatement(
    ResultSet.TYPE_SCROLL_INSENSITIVE,
    ResultSet.CONCUR_READ_ONLY
);
ResultSet rs = stmt.executeQuery("SELECT * FROM employee");

rs.last();   // go to last row
while (rs.previous()) {   // iterate in reverse
    System.out.println(rs.getInt(1) + " " + rs.getString(2));
}

ResultSetMetaData — Table Info at Runtime

Java — MetadataDemo.java
ResultSet rs = stmt.executeQuery("SELECT * FROM gtu");
ResultSetMetaData rsmd = rs.getMetaData();

System.out.println("Total columns: "        + rsmd.getColumnCount());
System.out.println("Column 1 name: "        + rsmd.getColumnName(1));
System.out.println("Column 1 type: "        + rsmd.getColumnTypeName(1));
06 — Transactions

Transaction Management & Isolation

A transaction is a unit of work. JDBC's Connection interface manages transactions. By default autoCommit = true — each statement is committed immediately.

MethodDescription
setAutoCommit(false)Disables auto-commit so you control when to commit
commit()Saves all changes made since last commit
rollback()Undoes all changes since last commit

Commit Example

Java — CommitDemo.java
conn.setAutoCommit(false);  // disable auto-commit
Statement stmt = conn.createStatement();
stmt.executeUpdate("INSERT INTO diet VALUES(605,'def','ci')");
conn.commit();              // save changes
conn.close();

Rollback Example

Java — RollbackDemo.java
conn.setAutoCommit(false);
stmt.executeUpdate("INSERT INTO diet VALUES(606,'ghi','ee')");
conn.commit();   // commit first insert

stmt.executeUpdate("INSERT INTO diet VALUES(607,'mno','ch')");
conn.rollback();  // undo second insert (606 stays, 607 removed)
conn.close();

Batch Processing

Execute multiple SQL statements at once for better performance:

Java — Batch.java
conn.setAutoCommit(false);
Statement stmt = conn.createStatement();

stmt.addBatch("CREATE TABLE DietStudent(enr INT PRIMARY KEY, name VARCHAR(20))");
stmt.addBatch("INSERT INTO DietStudent VALUES(6001,'java')");
stmt.addBatch("INSERT INTO DietStudent VALUES(6002,'php')");
stmt.addBatch("UPDATE DietStudent SET name='cg' WHERE enr=6002");

int[] results = stmt.executeBatch();  // execute all at once
conn.commit();

Important PYQ Programs

Program 1 — Employee Management (PYQ ★★★)

Insert multiple records using PreparedStatement, display all records in reverse order.

Java — EmployeeApp.java
import java.sql.*;

public class EmployeeApp {
    public static void main(String[] args) {
        try {
            Class.forName("com.mysql.jdbc.Driver");
            Connection conn = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/gtu", "root", "root");

            // CREATE TABLE (first time)
            Statement stmt = conn.createStatement();
            stmt.executeUpdate(
                "CREATE TABLE IF NOT EXISTS Employee(" +
                "Emp_ID INT PRIMARY KEY, EmpName VARCHAR(50)," +
                "Phone VARCHAR(15), Address VARCHAR(100))");

            // INSERT multiple records using PreparedStatement
            String sql = "INSERT INTO Employee VALUES(?,?,?,?)";
            PreparedStatement ps = conn.prepareStatement(sql);

            Object[][] data = {
                {101, "Alice", "9999100001", "Ahmedabad"},
                {102, "Bob",   "9999100002", "Surat"},
                {103, "Carol", "9999100003", "Rajkot"}
            };
            for (Object[] row : data) {
                ps.setInt   (1, (Integer) row[0]);
                ps.setString(2, (String)  row[1]);
                ps.setString(3, (String)  row[2]);
                ps.setString(4, (String)  row[3]);
                ps.executeUpdate();
            }
            System.out.println("3 records inserted.");

            // DISPLAY all records in REVERSE ORDER
            Statement s2 = conn.createStatement(
                ResultSet.TYPE_SCROLL_INSENSITIVE,
                ResultSet.CONCUR_READ_ONLY);
            ResultSet rs = s2.executeQuery(
                "SELECT * FROM Employee ORDER BY Emp_ID DESC");

            System.out.println("\n--- Employees (Reverse Order) ---");
            while (rs.next()) {
                System.out.println(
                    rs.getInt("Emp_ID")   + "\t" +
                    rs.getString("EmpName") + "\t" +
                    rs.getString("Phone")   + "\t" +
                    rs.getString("Address"));
            }
            ps.close(); s2.close(); conn.close();
        } catch (Exception e) { System.out.println(e); }
    }
}
Output
3 records inserted.

--- Employees (Reverse Order) ---
103   Carol   9999100003   Rajkot
102   Bob     9999100002   Surat
101   Alice   9999100001   Ahmedabad

Program 2 — Banking Application (PYQ ★★★)

Insert two records using PreparedStatement, display all records.

Java — BankApp.java
import java.sql.*;

public class BankApp {
    public static void main(String[] args) {
        try {
            Class.forName("com.mysql.jdbc.Driver");
            Connection conn = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/gtu", "root", "root");

            // CREATE TABLE
            Statement stmt = conn.createStatement();
            stmt.executeUpdate(
                "CREATE TABLE IF NOT EXISTS Bank(" +
                "AccountNo INT PRIMARY KEY, CustomerName VARCHAR(50)," +
                "Phone VARCHAR(15), Address VARCHAR(100))");

            // INSERT 2 records using PreparedStatement
            PreparedStatement ps = conn.prepareStatement(
                "INSERT INTO Bank VALUES(?,?,?,?)");

            ps.setInt   (1, 1001); ps.setString(2, "Ravi Patel");
            ps.setString(3, "9876543210"); ps.setString(4, "Bhavnagar");
            ps.executeUpdate();

            ps.setInt   (1, 1002); ps.setString(2, "Nita Shah");
            ps.setString(3, "9876543211"); ps.setString(4, "Surat");
            ps.executeUpdate();

            System.out.println("2 records inserted.");

            // DISPLAY all records
            ResultSet rs = stmt.executeQuery("SELECT * FROM Bank");
            System.out.println("\nAccountNo  Name           Phone        Address");
            System.out.println("--------------------------------------------------");
            while (rs.next()) {
                System.out.printf("%-10d %-14s %-12s %s%n",
                    rs.getInt(1), rs.getString(2),
                    rs.getString(3), rs.getString(4));
            }
            ps.close(); stmt.close(); conn.close();
        } catch (Exception e) { System.out.println(e); }
    }
}

--------------------------------------------------

1002       Nita Shah      9876543211   Surat
